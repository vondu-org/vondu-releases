# Vondu Public Releases

This repository hosts public, non-secret Vondu release assets that do not require a customer-specific license to download.

The local Docker installer release contains only the bootstrap script, Compose/runtime configuration, documentation, and public signature-verification keys. The Vondu Store Server application archive remains in the private `vondu-org/vondu` repository and is delivered through getvondu.com only after license authorization.

Do not upload application source archives, signing secrets, GitHub access tokens, purchase keys, or license data to this repository.
